Change your access token

For security, this must be done directly on the Windows computer running HomeWatch.

  1. Open the HomeWatch2 folder.
  2. Double-click Change-HomeWatch-AccessToken.cmd and approve the administrator prompt.
  3. Enter the new token twice. HomeWatch restarts automatically, then you can sign in here.
Use this only on a device you trust. HomeWatch never places the access token in the browser cookie.
